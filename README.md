# Hamburgueria_BlackBull

Projeto de criação de um pipeline de dados onde foi fornecido pelo contratante 208 planilhas xlsx de diversas áreas da empresa como Marketing, Finanças, Pedidos e Redes sociais.


O objetivo do projeto é criar um pipeline em Python que concatene todas as planilhas por área da empresa e as transforme em um banco de dados que possa ser tratado via SQL e posteriormente seja criado uma análise de BI utilizando o Power BI.

*Os dados do projeto, assim como o nome da empresa, foram alterados para manter o sigilo de dados sensiveis da empresa.
